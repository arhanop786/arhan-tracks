# Publishing Arhan Tracks to Google Play

The app is a PWA, so Play distribution uses a **Trusted Web Activity (TWA)**:
a thin Android wrapper that opens `https://arhan-tracks.pages.dev` full-screen
in Chrome, no browser UI, with your icons and splash. When you update the
website, the Play app updates automatically — **no Play re-review needed**.

---

## One-time setup (~30 min, no Android Studio)

1. **Java 17 (JDK)** — install from <https://adoptium.net>, then confirm:
   ```bash
   java -version
   ```
2. **Play developer account** — <https://play.google.com/console> (one-time
   $25 fee). Identity verification takes a day or two — start early.
3. That's it. `bubblewrap` (Google's official TWA generator) fetches the
   Android SDK bits itself on first run.

## Generate the Android project

```bash
npm run twa
```

Reads `.twa.config.json` (already in the repo) and runs Google's
`@bubblewrap/cli init` into `twa/`. It will ask a few questions — defaults
are fine. Bubblewrap creates a signing key (`twa/android.keystore`) —
**back this file up** and keep the passwords: lose it and you can never
update the app under the same listing.

## Build the release bundle

```bash
cd twa
./gradlew assembleRelease        # Windows: gradlew.bat assembleRelease
```

Output: `twa/app/build/outputs/bundle/release/app-release-bundle.aab`.

## Fill in the cert fingerprint

The first successful build prints (or `keytool -list -v -keystore
android.keystore` shows) a **SHA-256 fingerprint** of your signing key.

1. Put it in `.twa.config.json` as `"certFingerprint": "AA:BB:…"` and commit.
2. Replace the placeholder in `public/.well-known/assetlinks.json`
   (generated by `npm run twa`) with the same fingerprint.
3. Push — the deploy workflow publishes `assetlinks.json` automatically.
4. In **Play Console → Setup → App signing**, copy Google's *upload key*
   fingerprint too and add it to the same `assetlinks.json` list
   (`sha256_cert_fingerprints` is an array — both can live there).

Without this step the app shows a browser URL bar instead of running
full-screen — it still works, just not app-like.

## Play Console checklist

- **Store listing**: app name (≤30 chars), short description (≤80),
  full description (≤4000), 512×512 icon (use `public/icon-512.png`),
  **two+ phone screenshots** (capture from the installed app),
  feature graphic 1024×500.
- **Content rating questionnaire** → everyone.
- **Data safety form**: the app stores patient name + phone on your
  Supabase backend; declare "data collected, not shared, encrypted in
  transit". No ads, no third-party SDKs.
- **Privacy policy URL** — required. Serve `public/privacy.html`
  (already in the repo after you deploy) →
  `https://arhan-tracks.pages.dev/privacy.html`.
- **App category**: Medical.
- **Target audience**: 18+.
- **Release**: internal testing track first — install on your own phone,
  then promote to production when satisfied.

## Day-to-day

Nothing changes: edit the app → `git push` → live in ~35s, and the Play
app follows the site. Only touch `twa/` when bumping
`versionCode`/`versionName` (Play requires a new bundle with an increased
`versionCode` even for TWA apps) — edit `twa/app/build.gradle`, or re-run
`npm run twa` with a bumped `appVersion`/`appVersionCode` in the config.
